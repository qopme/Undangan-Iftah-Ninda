# Undangan Pernikahan Digital — Ninda & Iftah

Website undangan pernikahan digital bertema **Tradisional Jawa Minimalis** (*ivory/cream* `#F4EEE4`, cokelat tua `#5B4636`, *gold* lembut `#B59A70`, *sage* `#B9C0A7`, motif *kawung*, dan ilustrasi *line-art* pendopo Jawa).

## Pengaturan Foto Manual
1. Masukkan file foto ke dalam folder `assets/images/` (contoh: `cover.jpg`, `hero.jpg`, `ninda.jpg`, `iftah.jpg`, `story-1.jpg`, `galeri-1.jpg`, dll.).
2. Buka `assets/js/config.js` dan isi *path* file fotonya pada bagian `photos`, `stories`, dan `gallery`.
3. *Upload* repository ke layanan *hosting* statis (GitHub Pages, Netlify, Vercel, atau *web hosting*) lalu bagikan tautannya (bisa ditambah parameter `?to=Nama%20Tamu`).
